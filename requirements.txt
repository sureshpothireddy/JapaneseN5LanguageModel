# ============================================================
#  LinguaBridge: English <-> Japanese — requirements.txt
#  Python 3.11, 3.12, or 3.13
#
#  Install (inside your PyCharm virtualenv):
#      pip install -r requirements.txt
#
#  These use minimum-version floors (>=) rather than exact pins so
#  pip always grabs a prebuilt wheel for YOUR Python version and never
#  needs a C/C++ compiler. If you are on Python 3.13 this matters:
#  older pinned versions of numpy/matplotlib have no 3.13 wheels and
#  would try (and fail) to compile from source.
#
#  Platform notes for the microphone (speaking exercises):
#    Windows : pip install pyaudio          (ships prebuilt wheels)
#    macOS   : brew install portaudio  then pip install pyaudio
#    Linux   : sudo apt install portaudio19-dev  then pip install pyaudio
#  ffmpeg is optional (only used by pydub); the app runs fine without it.
# ============================================================
